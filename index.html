案例素材、重建与记录说明 ＋

JevDuo 是本页展示的 agent harness；复杂装配为交互案例，素材来自既有 NorthCUA 后端运行。本页不宣称 JevDuo 已执行这份轨迹。规划、CLI / GUI 执行、验证与恢复是能力说明，首屏装配演绎进度不作为实时代理日志。

桌面区使用原始 NorthCUA / BrickLink Studio 录像，精选搜索、放置、定姿与保存过程，并压缩推理等待。四路按装配进度对齐，不代表同一真实时刻；保存点来自原始工程记录。子模型切换及自建模块导入已标注，不生成虚假的 GUI 放置帧。CLI 辅助的约束模块不冒充逐件 GUI 装配。

3D 为 318 件彩色装配重建；运行展示使用已有 MuJoCo 求解记录，包含理想齿轮及离合器约束。网页不实时求解，不代表全零件接触、干涉或实物强度认证。本页仅整理展示，未新增模型调用、重新装配或修改原始轨迹和工程。Three.js 使用 MIT 许可证。

视觉研究参考 Atlas Motion 的工业产品节奏与 Igloo Inc 的连续场景衔接；页面、排版及展示对象独立制作，不复用其品牌或模型资产。
